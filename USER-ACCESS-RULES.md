# User Access Rules

## ADMIN
Full access to dashboard, products, stock in/out, customers, history, returns, reports, analytics, users and notifications.

## WAREHOUSE_USER / OUTLET_USER
Only these four menu items are available:
1. Product List (view only)
2. Product In
3. Product Out / Sale
4. Return Product

Users cannot add, edit or delete products. Product create/update/delete APIs are ADMIN-only.
